# 교내 카페 서비스 · 화면설계서와 기능명세서 (ver1.0)

팀원이 함께 보는 와이어프레임·화면 정의서·기능명세 통합 문서 사이트와, 문서와 독립된 Live Demo입니다.

## 메뉴 구성
| 메뉴 | 주소 | 설명 |
|---|---|---|
| 전체 흐름 보기 | `#/flow` | 화면 카드 목록, 정적 미리보기, [문서 보기] / [시연하기] |
| 문서 보기 (첫 진입) | `#/doc/W1` ~ `#/doc/W4` | 화면 개요, 구성 요소, 번호별 프레임, 기능명세 |
| 시연하기 | `#/demo/W1` ~ `#/demo/W4` | 실제 React 상태로 동작하는 독립 데모 (화면별 직접 진입 가능) |

주소는 해시 라우팅이라 Vercel에서 별도 rewrite 설정 없이 새로고침·직접 진입이 동작합니다.

## 개발자용 실행 방법
```bash
npm install
npm run dev      # 개발 서버
npm run lint     # tsc --noEmit (타입 검사)
npm run build    # 타입 검사 + 프로덕션 빌드 → dist/
```
Vercel: Framework Preset `Vite`, Root Directory `./`, Build Command `npm run build`, Output Directory `dist`.

## 자료 출처
- 읽은 자료: 기획 대화에서 작성한 와이어프레임 W1~W4, IA, User Flow, 기능 정의
- **읽지 못한 자료**: Figma Dev Mode 추출 코드(미첨부), Notion IA/User Flow 링크(접근 불가)
- 따라서 화면은 Figma 원본이 아니라 와이어프레임을 React로 다시 구현한 것입니다.

## Mock 범위
메뉴·가격·최근 주문·픽업 슬롯·대기 시간은 모두 Mock입니다. 결제는 실제로 처리되지 않고(0.7초 후 성공, 데모 패널에서 실패 설정 가능), 푸시 알림과 서버 연동은 없습니다.

## 저장 조건
시연 상태는 메모리에만 있어 새로고침하면 초기화됩니다. 실제 서비스의 유지 정책은 **확인 필요**입니다. 직접 진입(`#/demo/W3`, `#/demo/W4`)은 목업 초기 상태(장바구니·주문)로 시작합니다.
