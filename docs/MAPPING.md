# 화면 · 프레임 · 구성 요소 · Feature 매핑

구성 요소 번호는 원본 번호가 아니라 **문서용 번호 (화면 정의서 구성 순서)** 입니다. 번호 위치는 화면 요소의 `data-no` 속성과 실제 DOM 위치로 계산합니다.

| 화면 ID | 화면명 | 원본 프레임 | Route | 구성 요소 번호 → Feature | 출처 |
|---|---|---|---|---|---|
| W1 | 홈 | 와이어프레임 W1 | #/doc/W1, #/demo/W1 | 01 헤더(F-03) · 02 최근 주문(F-02) · 03 메뉴 목록(F-03) · 04 담은 메뉴 바(F-01) · 05 탭바 | 기획 대화 |
| W2 | 메뉴 상세 | 와이어프레임 W2 | #/doc/W2, #/demo/W2 | 01 헤더 · 02 메뉴 정보(F-03) · 03 필수 옵션(F-03) · 04 추가 옵션(F-03) · 05 수량(F-03) · 06 하단 버튼(F-03, F-01) | 기획 대화 |
| W3 | 주문하기 | 와이어프레임 W3 | #/doc/W3, #/demo/W3 | 01 헤더 · 02 주문 메뉴(F-01) · 03 픽업 시간(F-01) · 04 결제 수단(F-04) · 05 결제 버튼(F-04, F-01) | 기획 대화 |
| W4 | 주문 현황 | 와이어프레임 W4 | #/doc/W4, #/demo/W4 | 01 픽업 번호 · 02 상태 · 03 알림 안내 · 04 주문 내용 (모두 F-05) · 05 탭바 | 기획 대화 |

| Feature | 기능명 | 연결 화면 |
|---|---|---|
| F-01 | 픽업 시간 예약 주문 | W3 (W1 담은 메뉴 바, W2 하단 버튼) |
| F-02 | 빠른 재주문 | W1 |
| F-03 | 메뉴 조회 · 옵션 선택 | W1, W2 |
| F-04 | 간편 결제 | W3 |
| F-05 | 주문 현황 · 준비 완료 알림 | W4 |

원본 Figma 프레임 번호와 구성 요소 번호는 자료가 없어 연결하지 않았습니다. 화면·기능 수는 `src/data.ts`에서 계산합니다.
